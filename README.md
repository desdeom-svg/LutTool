# LutTool Professional - 工业视觉 LUT 调优工具

![LutTool Version](https://img.shields.io/badge/Version-2.0.0-blue.svg)
![Python](https://img.shields.io/badge/Python-3.8+-green.svg)

**LutTool Professional** 是一款专为工业视觉应用设计的专业级 LUT (Look-Up Table) 编辑与优化工具。它支持多通道独立控制、ROI 区域量化评估、自动寻优算法以及行业领先的“反向 LUT 推导”功能，旨在帮助工程师快速提取并还原图像增强模型。

---

## 🚀 核心功能

### 1. 多通道独立控制 (RGB/Grayscale)
- **RGB 全通道同步**：一键调整亮度与对比度。
- **独立通道微调**：支持对 R、G、B 通道进行单独的曲线拉伸，实现精准的色彩平衡调整。
- **智能适配**：自动识别单通道灰度图与三/四通道彩色图，锁定非法操作。

### 2. ROI 区域评估与量化 (Professional Metrics)
- **CNR (对比信号噪比)**：通过实时框选“缺陷区域”与“背景区域”，自动计算画面对比度质量。
- **类间方差**：利用大津算法原理评估目标与背景的可分割程度。
- **信息熵 (Entropy)**：量化处理后图像的细节保留程度。

### 3. 反向 LUT 推导 (Reverse Engineering)
- **直方图模式 (Histogram)**：【默认推荐】基于色彩分布概率进行映射，完全免疫图像位移和对齐误差。
- **全灰阶模式 (Full)**：1:1 像素级映射，捕捉最精细的亮度跳变。
- **少量灰阶模式 (Sparse)**：基于 17 个关键控制点拟合，生成极致平滑的算法曲线，便于二次开发。

### 4. 自动化工具箱
- **自动拉伸 (Auto Stretch)**：基于图像动态范围自动计算黑白场。
- **直方图均衡化 (HE)**：一键提升图像细节。
- **智慧寻优 (Auto Search)**：搜索最佳 Gain/Offset 组合，最大化信号对比度。

## 📖 操作指南

### 基础流程
1. **导入图片**：点击左侧工具栏“导入图片”加载参考图 (Input)。
2. **绘制 ROI**：在图像窗口按下鼠标左键拖动。第一个框为“缺陷区”(红色)，第二个框为“背景区”(绿色)。
3. **调整曲线**：在右侧曲线编辑器中拖动控制点。
    - **鼠标左键**：移动点。
    - **鼠标右键**：添加/删除点。

### 反向推导 LUT (获取他人算法模型)
1. 导入您的原始参考图。
2. 点击【智能工具箱】->【反向推导 LUT】。
3. 选择推导策略（彩色图建议选“直方图”）。
4. 选择对应的效果图 (Output)，系统将自动生成等效的 LUT 曲线并实时应用。
